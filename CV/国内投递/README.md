## 面试主动要讲的四个故事

| 简历 | 核心卖点 |
|---|---|
| `CV_hpc` | ARCHER2 32 节点 / 4,096 核、408 runs 对照实验、hybrid 布局调优、NUMA / CCX 与线程绑定的实际验证 |
| `CV_perf` | Linaro MAP 把开销拆成计算 / 通信 / 同步等待三类；MPI 占比 46.7%→6.2% 与 OpenMP 空转 48.3%→76.5% 的交点即最优布局 |
| `CV_backend` | 六层分层架构 + CLI / FastAPI 双进程边界 + 229 项自动化测试全量离线可跑；trace_id 贯穿的可回放事件流。支付域会问一致性 / 幂等 / 对账 —— 幂等目前只在技能段的「了解」层 |
| `CV_agent` | 把 Agent 正确性变成可评测量：规则 router 83.3% vs LLM 100%；去掉 system prompt 掉到 63.3%；三类异常统一收敛为显式 unknown，绝不猜参数 |

**对着 Agent 岗的 JD 逐条自查**（腾讯 2027 那份最典型）：Tool Use ✓、Agent 评测与质量体系 ✓✓、
RAG ✓（词法）、Planning / Memory / Reflection ✗、多 Agent 编排 ✗、
LangGraph / AutoGen / CrewAI / MetaGPT ✗。
**「Agent 评测与质量体系建设」是它的明写加分项，也是大多数应届生讲不出来的一格**——
这是你和「调过 API」的人之间的差别，面试里要主动讲。缺口那几项见 `../README.md` 开放待办 8、9。

**通用高价值故事（所有技术岗都适用）**：主动作废 302/303 份文件名与实际 MPI 进程数不符的日志、
废弃整个阶段的性能曲线，并把「从日志内容而非文件名解析」写成分析入口的硬校验——
这是科学诚信与数据洁癖的强信号，在 DeepSeek / 幻方、NVIDIA、研究院所是明确加分项。

**MARL 专属故事**（网易伏羲、地平线、Momenta 等有 RL 团队的地方）：MAPPO-QMIX 不收敛的根因诊断——
TD 目标沿用 value-based 的 `max_a Qᵢ` 而 actor 是 on-policy，`td_error` 并非合法 advantage；
并定位 `softplus(0) ≈ 0.69` 的 mixing 权重对局部 Q 的梯度做乘性放大。

## 秋招时间线（2026-08 视角）

你学位证书 2026.12 获得 → 毕业时间落在 2026.9–2027.8 区间 → 多数公司算你 **2027 届**。

2027 届秋招的常见节奏（各家差异不小，以目标公司官网为准）：

- **提前批**：6–8 月，很多大厂 7 月就开了 —— **现在已经在尾声**
- **正式批**：8–10 月开放，**9 月是峰值**
- 11 月起基本收尾，之后主要靠补录和春招

**也就是说现在正是窗口期，而且提前批那一段已经过去大半。**
